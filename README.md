# 🧁 Loja de Cupcake 

> Projeto acadêmico desenvolvido para a disciplina de Projeto Integrador Transdisciplinar em Engenharia de Software II, do curso de Engenharia de Software, da universidade Cruzeiro do Sul. Com o principal foco na integração entre interface web, linguagem de programação em Python e validação de dados em banco de dados SQLite na nuvem.

🔗 **Acesse o projeto online:** https://projeto-cupcake-ppwp.onrender.com/

---

-> Sobre o Projeto

O **Loja de cupcake** é uma aplicação web completa que simula o fluxo de vendas de uma confeitaria. 
O sistema permite que os clientes visualizem o catálogo de produtos atualizado  a partir do banco de dados, adicionem itens ao carrinho e registrem pedidos.

-> Funcionalidades
- **Catálogo Dinâmico:** Lista de sabores, descrições, preços e disponibilidade , carregados diretamente do banco de dados.
- **Carrinho de Compras:** Adição, remoção e cálculo automático do valor total do pedido.
- **Registro de Pedidos:** Envio e armazenamento dos dados da compra no banco de dados.
- **Painel Administrativo:** Cadastro e atualização de novos sabores de cupcakes.

---

-> Tecnologias Utilizadas

- **Frontend:**  JavaScript, Html e CSS 
- **Backend:** Python 
- **Banco de Dados:** SQLite 
- **Infraestrutura e Deploy:** GitHub + Render
